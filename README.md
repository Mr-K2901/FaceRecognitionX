# FaceRecognitionX

FaceRecognitionX is a **phase-wise, deployable computer vision project** focused on building a
real-time face recognition system using **Laptop Camera and ESP32-CAM** as video sources.

The project is designed and developed **step by step**, with clear separation of concerns,
clean abstractions, and production-oriented GitHub practices.

---

## 🎯 Project Goals

- Build a **real-time video pipeline** from scratch
- Support **multiple video sources** (Laptop Webcam + ESP32-CAM)
- Implement **face detection & recognition** in later phases
- Maintain **low-latency, stable streaming**
- Follow **industry-style Git workflow** and documentation
